Welcome to my personal blog! This is a simple example post to get you started.

## How to Create Posts

To create a new blog post, simply add a new markdown file to the `_posts` folder with the following naming convention:

```
YYYY-MM-DD-post-title.md
```

## Front Matter

Each post needs YAML front matter at the top:

```yaml
---
layout: post
title: "Your Post Title"
date: 2026-01-08 10:00:00 -0800
---
```

## Features

- ✅ Posts automatically appear on the main page
- ✅ Posts are sorted by date (newest first)
- ✅ Search bar filters posts by title
- ✅ Responsive design with midnight theme
- ✅ GitHub Pages compatible

Just commit and push your new posts, and they'll automatically show up on your blog!
