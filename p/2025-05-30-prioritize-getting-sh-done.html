Prioritize Getting Sh*t Done

[Reflection] [2025-05-30]

I finally started putting my daily writing online. It's been approximately two months of daily practice. I feel better knowing that I created something for the day. However, before the first word is put down, it mostly feels bad. So now the goal is a simple three-step process: 1. Write nearly every day. 2. Write with a pen and paper, not a computer. 3. A few times a week, consolidate and publish writing online so it's archived forever.

EDIT [Jan 8, 2026]: Trying again with this GitHub Pages-hosted blog now.
