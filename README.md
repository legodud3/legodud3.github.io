# My Blog

A simple personal blog powered by Jekyll and GitHub Pages.

## Quick Start

1. **Add a post**: Create a markdown file in the `_posts` folder with format `YYYY-MM-DD-title.md`
2. **Write content**: Add YAML front matter with `layout: post`, `title`, and `date`
3. **Commit & push**: Your post will automatically appear on the blog

## File Structure

```
.
├── _config.yml          # Jekyll configuration
├── _posts/              # Blog posts go here
├── _layouts/            # Custom layouts
├── index.md             # Home page with post list and search
└── Gemfile              # Ruby dependencies
```

## Using the Search

The main page has a search bar that filters posts by title in real-time as you type.

## Customization

Edit `_config.yml` to change:
- Site title, description, author
- GitHub profile link
- Other Jekyll settings
